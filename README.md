# MyApp

A full-stack application using:

- React
- TypeScript
- Vite
- ASP.NET Core Web API
- .NET 10

## Project structure

```text
frontend/  React TypeScript application
backend/   ASP.NET Core API
```

## Development

| Service  | URL                     |
|----------|--------------------------|
| Frontend | http://localhost:5173   |
| Backend  | http://localhost:8000   |

Run both together:

```bash
npm run dev
```
